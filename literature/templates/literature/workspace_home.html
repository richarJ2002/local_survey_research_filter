Save project copy / Backup / Restore

Save Copy makes a self-contained project with a new ID, including committed edits while the source is open. Backup keeps the original ID. For Backup or Restore, Exit all project tabs, then Close worker here. Workers owned by another manager must be closed there.

Copies include only project.json and project.sqlite3. Required symlinks are materialised. Generated exports, backups, arbitrary files, app settings, authentication and sessions are excluded. Re-export charts or Markdown from the copy if needed. Destination parent must exist; Save Copy/Backup never overwrite populated folders. Restore requires a distinct same-ID backup and keeps the entire previous folder in a recovery sibling.
